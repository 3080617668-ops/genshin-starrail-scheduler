# 原神 · 崩铁定时助手

给 BetterGI 和三月七助手统一安排执行时间：按计划启动、依次运行，并查看运行记录。

这是独立的 Windows 调度工具。游戏内的具体操作由你自行安装和配置的 BetterGI、三月七助手执行。

## 功能

- 自动查找两款助手，也支持手动选择路径。
- 每天、每周或单次执行，支持分别设置时间。
- 两款游戏串行执行；同一时间可选择先后顺序。
- 立即运行、停止当前及排队任务、设置超时。
- 可选开始时黑屏静音；手动按 Esc 恢复画面和原来的静音状态。
- 显示下次执行时间和当天日志；关闭设置窗口后仍可按计划执行。

## 下载与开始

到本仓库的 **Releases** 下载测试版 ZIP，解压到固定文件夹，双击 `游戏定时助手.exe`。保留同目录的 `BlackScreenMute.Game.exe`。

1. 先分别安装并手动验证 [BetterGI](https://www.bettergi.com/doc.html) 和 [三月七助手](https://github.com/moesnow/March7thAssistant)。本项目不包含这两款助手或游戏客户端。
2. 点击“自动查找”或“浏览”，选择助手位置；原神选择一条龙配置。
3. 检查各助手的任务、队伍和资源消耗设置。BetterGI 完成后操作应设为“关闭游戏和软件”。
4. 先手动试跑，再设置时间并点击“应用定时计划”。“保存设置”不会更新 Windows 定时任务。

完整步骤见 [使用说明](使用说明.md)。

## 使用条件与测试状态

- 面向 Windows 10/11 x64；编译使用系统 .NET Framework 工具链。
- 电脑必须开机，Windows 已登录、桌面解锁；运行期间不要操作鼠标键盘。
- 睡眠唤醒取决于硬件和 Windows 设置；唤醒后仍锁屏会跳过任务。
- 黑屏是窗口覆盖，显示器仍通电。任务结束后保持黑屏静音，手动按 Esc 恢复；Esc 不会取消游戏任务。
- 原始开发版本已完成模拟流程、界面及本机黑屏兼容性检查；**尚未验证真实游戏的完整流程**。公开测试版需要在实际环境中试跑。
- 具体游戏任务和运行结果取决于所用助手版本及配置。本项目不保证奖励到账，也不承诺账号使用风险为零。

## 从源码编译

在项目目录使用 PowerShell 执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

生成 `游戏定时助手.exe` 和 `BlackScreenMute.Game.exe`。首次运行的助手路径为空，定时计划默认关闭；个人设置保存在本地 `settings.json`。
